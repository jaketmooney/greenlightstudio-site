Product render demo

From plain model to finished imagery

Two stock 3D models, stripped back to raw grey geometry like a CAD export, taken to studio renders and animation by Claude working in Blender. Every step was started by a short plain-English message, shown here exactly as it was sent. Claude reused a studio set-up (lights, cameras, material library) it built on an earlier product job, so each new product starts from there. The last stage places the finished renders into website and print mock-ups; the brand names, copy and web addresses in those are invented placeholders.

Drag the slider: raw grey on the left, finished on the right.

One-time setup

Connect Claude Code to Blender

  1. Step 1

    Install uv

    A small helper that runs the connector. In PowerShell:powershell -c "irm https://astral.sh/uv/install.ps1 | iex"

  2. Step 2

    Add the Blender add-on

    Download addon.py from github.com/ahujasid/blender-mcp. In Blender: Edit → Preferences → Add-ons → Install…, then tick “Interface: Blender MCP”.

  3. Step 3

    Add it to Claude Code

    One command, no config files:claude mcp add blender uvx blender-mcp

  4. Step 4

    Connect from Blender

    In the 3D Viewport press N, open the BlenderMCP tab and click “Connect to Claude”.

Then just ask: “Make a red metallic sphere floating above a blue cube.” The first command after connecting sometimes fails; a second message usually works. Needs Blender 3.0 or newer (4.x recommended), Python 3.10+ and Claude Code. Claude can run Python inside Blender, so save your scene first. Steps from blendermcp.org/setup/claude.

This demo’s renders ran as background Blender scripts started from Claude Code. The live link above lets Claude work inside an open Blender window instead.

Every project

How it works

  1. Step 1

    You ask

    Send a short plain-English message, such as “strip it back to raw grey” or “make the paint glossy yellow”.

  2. Step 2

    Claude writes

    Claude turns your message into short scripts for Blender, built on a studio kit of lights, cameras and materials.

  3. Step 3

    Blender renders

    Claude runs Blender in the background, with no clicking. Blender loads the model, applies the look and renders the images and clips.

  4. Step 4

    Claude checks

    Automatic checks and a look at the image first, then the result comes back to you. Your next message starts the next step.

Blender is free 3D software; Claude drives it by writing scripts for it. Everything on this page ran on one computer.

What we’d need from you

  • Your 3D model or CAD fileSTEP, OBJ, FBX, GLB or similar. No model yet? Tell us what you have.
  • Brand assetsLogos (vector if possible), colour codes, fonts and any livery or label artwork.
  • FinishesPaint colours (RAL or Pantone), metals, glass and rubber. Samples or photos help.
  • Reference photosReal photos of the product, plus any looks you like or want to avoid.
  • What you need madeThe stills (angles and looks) and clips (length, widescreen or vertical), and where they will be used, so size and crop match.
  • One person for notesA single contact for feedback keeps each round quick.
